# Legacy Shiny app (until 2023)

The previous version of the Awesome Geodata Table: a Shiny app reading a Google Sheet
(`app.R`, `R/`, `www/`) and the R Markdown site (`index.Rmd`). It was replaced in
October 2026 by the static Quarto/reactable site in the project root. The legacy sheet
export `extdata/awesome_geodata_table.csv` was migrated with `data-raw/migrate_v1.R`.

Kept for reference only – nothing in here is used by the build. Safe to delete.
